# Security Lab

보안 진단 포트폴리오를 위한 로컬 전용 테스트 환경입니다.

실무에서 수행해 온 웹/API, 모바일, C/S, AI 서비스 진단 방식을 고객사 자료 없이 재현하기 위해 구성합니다.  
취약 버전과 개선 버전을 함께 제공해 **진단 → 원인 분석 → 개선 → 재점검** 흐름을 확인할 수 있도록 만드는 것이 목적입니다.

## 현재 구성

### 1. Web / API Security Lab
- SQL Injection
- Reflected XSS
- 인증 / 세션
- IDOR / 접근통제
- 중요정보 노출
- 취약 구현과 개선 구현 비교

[Web / API Security Lab 바로가기](./web-api/README.md)

## 운영 원칙

- 로컬 테스트 전용
- 인터넷에 직접 노출하지 않음
- 실제 개인정보나 고객사 정보를 사용하지 않음
- 모든 계정과 데이터는 테스트용
- 취약 코드와 개선 코드를 함께 유지
