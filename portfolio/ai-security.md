# AI Security

최근 프로젝트에서 AI 챗봇 보안진단을 수행했습니다.

웹 취약점 점검과 달리 정해진 Payload 하나로 판단하기 어려워서, 질문 방식을 바꾸거나 역할을 부여하고 반복 질의를 하면서 서비스가 내부 지시나 정보를 어느 정도까지 노출하는지 확인했습니다.

주로 확인했던 내용은 다음과 같습니다.

- Prompt Injection
- 역할극이나 문맥 변경을 통한 제한 우회
- 반복 질의에 따른 정보 누적 노출
- 내부 지시나 정책 노출 가능성
- 사용자 권한에 따라 제한되어야 할 정보 접근 여부
- 민감정보가 모델 Context에 불필요하게 포함되어 있는지 여부

문제가 확인되면 단순히 특정 문장을 차단하는 것보다, 민감정보를 모델에 전달하는 구조와 사용자별 데이터 접근 범위, API 호출 전 권한검증 같은 부분을 함께 봅니다.

실제 고객사의 프롬프트나 내부정보는 공개하지 않습니다.
