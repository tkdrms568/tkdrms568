# C/S

제조 환경의 C/S 프로그램을 진단하면서 .NET 기반 클라이언트 분석과 통신 흐름 확인을 경험했습니다.

주로 사용한 도구는 dnSpy와 EchoMirage였습니다.

분석할 때는 다음을 같이 봅니다.

- 클라이언트 내부의 인증·권한 로직
- 입력값 검증 위치
- 서버로 전달되는 파라미터와 상태값
- 로컬에 포함된 중요정보
- 클라이언트 검증을 우회했을 때 서버가 다시 확인하는지 여부

코드만 보거나 통신만 보는 것보다, 실제 화면에서 기능을 실행한 뒤 관련 메서드와 통신을 연결해서 보는 방식이 도움이 됐습니다.

현재는 고객사 자료를 공개하지 않고, 별도 테스트 프로그램에서 동일한 분석 과정을 재현할 수 있도록 준비하고 있습니다.
