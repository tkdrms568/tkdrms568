## Security Lab 연결

이 포트폴리오는 저장소의 [Web / API Security Lab](../security-lab/web-api/README.md)을 로컬에서 실행해 직접 진단한 결과로 채웁니다.

## 10. 개선 및 재점검

발견된 취약점은 단순히 재현 화면만 남기지 않고 다음 기준으로 정리합니다.

1. 취약점 발생 위치
2. 재현 조건
3. 발생 원인
4. 실제 서비스 영향
5. 개발자가 적용할 수 있는 조치 방향
6. 조치 후 동일 시나리오 재점검
7. 유사 기능의 동일 취약점 존재 여부 확인
