# Mobile

모바일 진단은 앱 화면만 보는 방식보다, 앱 내부 보안 로직과 서버 API를 같이 보는 편입니다.

실무에서 주로 확인했던 내용은 다음과 같습니다.

- Root Detection 동작 방식 확인
- SSL Pinning 적용 여부와 우회 가능성 확인
- Frida를 이용한 메서드 호출 및 런타임 값 확인
- 앱 내부에 포함된 중요정보나 보안 로직 확인
- 우회 이후 실제 API와 권한 처리까지 추가 검증

Root Detection이나 Pinning을 우회하는 것 자체가 목적은 아닙니다. 우회 이후에도 서버에서 권한과 입력값을 제대로 검증하는지, 클라이언트 보안 기능이 실제 보안 경계처럼 사용되고 있지는 않은지를 확인합니다.

고객사 APK나 내부 코드는 공개할 수 없어, 추후 공개 가능한 테스트 앱에서 동일한 분석 흐름을 다시 정리할 예정입니다.
