# Portfolio Evidence

포트폴리오에 사용하는 스크린샷과 다이어그램을 저장하는 위치입니다.

## 권장 구조

```text
assets/
├─ web-api/
├─ mobile/
├─ cs/
├─ ai/
└─ vulnerability-management/
```

## 업로드 전 확인

- 고객사명, URL, IP, 계정정보가 포함되어 있지 않은지 확인
- Cookie, Authorization Header, Token 등 인증정보 제거
- 실제 개인정보 및 내부정보 제거
- 로컬 테스트 환경 또는 공개 실습 환경인지 확인
- 불필요한 브라우저 탭, 북마크, 개인 계정정보 제거
- 캡처만으로 이해하기 어려운 경우 간단한 설명 또는 화살표 추가
