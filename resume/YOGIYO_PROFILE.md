# 요기요 지원용 프로필

## 소개

정보보호 분야에서 약 7년간 금융·제조·공공·교육 환경의 웹·모바일·API·C/S·인프라 취약점 진단과 모의해킹을 수행해 왔습니다.

서비스 구조와 요청·응답 흐름을 먼저 이해한 뒤 인증·인가, 입력값 검증, 중요정보 노출, 파일 처리, API 및 업무 로직 등 실제 공격면을 검증하는 방식으로 진단해 왔습니다. 취약점 존재 여부만 확인하는 것이 아니라 사용자별 권한 차이와 파라미터 변조 결과를 비교해 서버에서 실제 검증이 이루어지는지 확인하고, 발생 원인과 영향도를 분석해 조치 방향 협의와 재점검까지 연결하는 업무를 중심으로 경험했습니다.

모바일 환경에서는 SSL Pinning, Root Detection 등 보안 로직을 분석하고 필요한 경우 우회 후 API와 권한 처리까지 연계해 검증했으며, Frida를 활용한 런타임·메모리 분석 경험이 있습니다. C/S 환경에서는 dnSpy, EchoMirage 등을 활용해 클라이언트 로직과 통신 구조를 분석했습니다.

최근에는 AI 챗봇 서비스를 대상으로 Prompt Injection, 의도하지 않은 응답 유도, 내부정보 및 민감정보 노출 가능성을 점검하고 서비스 구조를 고려한 개선방안을 제시했습니다. 또한 반복적인 진단 업무를 효율화하기 위해 개인적으로 웹·API 중심 자동 진단 도구를 고도화하고 있으며, 로그인 이후 공격면 수집, 다계정 권한 비교, 취약점 재현 정보와 Evidence 제공 방식 등을 검토하고 있습니다.

PM/PL 역할을 수행하면서 진단 범위·일정·주요 이슈·결과 검토·고객 및 유관부서 커뮤니케이션·조치 후 재점검까지 관리해 왔습니다. 앞으로는 외부 진단 프로젝트 단위의 업무를 넘어 하나의 서비스와 조직을 지속적으로 이해하면서 취약점 발견부터 조치·관리·재점검까지 이어지는 기술보안 업무를 수행하고자 합니다.
