# 박상근 | Technical Security / Application Security

**정보보호 경력 약 7년**

웹·모바일·API·C/S·인프라 취약점 진단과 모의해킹을 수행해 왔으며, 취약점 발견에서 끝나지 않고 원인·영향도 분석, 조치 협의, 재점검까지 연결하는 업무를 중심으로 경험했습니다. 최근에는 AI 챗봇 보안진단과 개인 자동 진단 도구 고도화를 통해 AI·자동화 영역까지 업무 범위를 넓히고 있습니다.

## 핵심 역량

- **Web / API Security**: 인증·인가, 입력값 검증, 중요정보 노출, 파일 처리, API 및 업무 로직 취약점 진단
- **Mobile Security**: SSL Pinning·Root Detection 분석 및 우회, Frida 기반 런타임·메모리 분석
- **C/S Security**: dnSpy·EchoMirage 기반 클라이언트 로직 및 통신 구조 분석
- **AI Security**: AI 챗봇 Prompt Injection 및 내부정보·민감정보 노출 가능성 점검
- **Vulnerability Management**: 취약점 원인·영향도 분석, 조치 방향 협의, 개선 결과 확인 및 재점검
- **Security Automation**: 개인 웹·API 자동 진단 도구 고도화, 로그인 이후 공격면 수집·다계정 권한 비교·Evidence 제공 방식 검토
- **PM / PL**: 범위·일정·이슈·결과 검토·고객 및 유관부서 커뮤니케이션·결과보고
