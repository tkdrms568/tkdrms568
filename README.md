# 박상근 | 정보보호 컨설턴트 · 모의해킹 / 취약점 진단

약 7년간 금융·제조·공공·교육 등 다양한 산업군에서 **웹·모바일·인프라 취약점 진단과 모의해킹**을 수행해 왔습니다.

단순히 취약점을 찾는 데 그치지 않고, **공격 가능성 확인 → 원인 및 영향도 분석 → 조치 가이드 제시 → 재점검**까지 이어지는 진단 업무를 중요하게 생각합니다.  
최근에는 PM/PL 역할을 수행하며 진단 범위, 일정, 이슈, 고객 커뮤니케이션과 결과 품질 관리까지 프로젝트 전반을 맡고 있습니다.

---

## 주요 역량

| 영역 | 수행 경험 |
|---|---|
| **웹 / API 보안** | 인증·세션 흐름 분석, 권한별 요청 비교, 입력값·파라미터 변조, 파일 처리, 중요정보 노출, 비즈니스 로직 검증 |
| **모바일 앱 보안** | Android 앱 취약점 진단, API 통신 분석, Root Detection / SSL Pinning 등 보안 기능 동작 확인 및 우회 가능성 검증 |
| **권한 검증** | 일반 사용자·관리자 간 요청 비교, 객체 ID 및 파라미터 변조를 통한 수평·수직 권한 검증 |
| **인프라 보안** | 서버·네트워크·WEB/WAS 취약점 진단, 계정·권한·접근통제·불필요 서비스·보안 설정 점검 |
| **소스코드 보안 점검** | 소스코드를 분석하여 취약 가능 영역을 식별하고, 발생 원인·영향도 분석 및 수정 가이드 제공 |
| **써드파티 앱 검수** | 외부·제휴 애플리케이션의 권한, 개인정보 처리, API 연동 및 입력값 검증 관점의 보안 검수 |
| **취약점 개선 관리** | 확인된 취약점의 원인 및 영향도 분석, 개발·인프라 담당자 대상 조치 가이드, 개선 결과 재점검 |
| **PM / PL** | 진단 범위·일정·이슈·산출물 관리, 고객 및 유관부서 커뮤니케이션, 결과 검토 및 보고 |

## 실제 진단 시 중점적으로 보는 부분

### 웹 · API
- 로그인 및 인증·세션 처리 흐름
- 사용자 및 권한별 요청·응답 차이
- 서버 측 권한 검증 및 리소스 소유권 검증
- 입력값·파라미터 변조에 대한 서버 측 검증
- 비정상 입력, 특수문자, 경계값, 데이터형 변조 테스트
- 파일 업로드·다운로드 및 중요정보 처리 로직
- 화면 단의 제어와 서버 단의 실제 검증 차이

### 모바일
- 주요 기능과 백엔드 API 호출 흐름
- Root Detection, SSL Pinning 등 보안 기능 적용 상태
- 보안 솔루션 우회 가능성 및 우회 이후 노출되는 공격면
- 앱 내 중요정보 저장·처리 방식
- 클라이언트 측 검증과 서버 측 검증의 차이

### 인프라
- 계정 및 권한 관리
- 네트워크 접근통제
- 불필요 서비스 및 관리 인터페이스 노출
- WEB/WAS 보안 설정
- 실제 운영 환경을 고려한 개선방안 도출

## 취약점 대응 방식

1. **서비스 구조와 업무 흐름 파악**
2. **공격면 및 검증 포인트 식별**
3. **요청·응답 분석과 변조 테스트 수행**
4. **취약점 발생 원인과 실제 영향도 분석**
5. **개발·인프라 담당자가 적용 가능한 조치 가이드 제공**
6. **조치 이후 동일 시나리오 기반 재점검**

취약점의 개수보다 **실제 악용 가능성과 서비스 영향**, 그리고 **개선까지 연결되는 결과**를 중요하게 생각합니다.
